Dashu 用户指南

本页面记录了 dashu 的数值类型在哪些方面符合相关标准——以及在哪里有意偏离。有两个方面：

  • dashu-float 的 FBig 与 IEEE 754-2008——实数浮点模型。
  • dashu-cmplx 的 CBig 与 C99 Annex G（IEC 60559 兼容复数运算）——复数模型，基于 FBig 构建，继承其有符号零 / 有符号无穷行为。

共同的主线是：dashu 类型是任意精度的，因此固定位宽编码的相关问题（次正规数、NaN 负载、位布局）没有直接对应物。当无限精度使标准规则自然满足时，它们即被满足；当它们与任意精度 / 无 NaN 模型冲突时，偏离之处已被注明。

dashu-float 与 IEEE 754-2008

此处的参考标准是 IEEE Std 754™-2008（ISO/IEC/IEEE 60559:2011）。

数据模型

第 3 节——浮点格式

IEEE 754 要求合规性说明
二进制和十进制格式✅ 支持FBig<Rounding, 2>（二进制）和 DBig = FBig<HalfAway, 10>（十进制）。其他基数通过 const BASE: Word 参数支持。
有限非零数✅表示为 significand×BASEexponent，尾数无界。
有符号零（±0）✅通过指数哨兵值编码：+0 ↔ 指数 0，-0 ↔ 指数 -1。由算术运算、舍入和消去按 IEEE 754 产生。
有符号无穷（±∞）✅通过指数哨兵值编码：+∞ ↔ isize::MAX，-∞ ↔ isize::MIN。
NaN❌ 偏离无 NaN。无效运算在便捷层 panic，在 Context 层返回 Err(FpError)。
次正规数不适用任意精度尾数消除了对次正规数的需要。任何非零数都是规范化的。
固定位宽编码不适用无固定位宽；尾数是无界的 IBig 整数。

算术运算

第 5 节——运算

IEEE 754 要求合规性说明
±0 比较相等✅在 PartialEq、Ord、NumOrd 中 +0 == -0。
±∞ 同符号比较相等，与有限数有序比较✅+∞ == +∞，+∞ > 有限数，-∞ < 有限数。
上溢 → ±∞（符号取决于舍入模式）✅在 Repr 层检测，在 Context 层返回 Err(FpError::Overflow(sign))，在 FBig 层转换为有符号无穷。
下溢 → ±0✅与上溢机制相同。
finite / ±0 → ±∞✅作为值产生（而非错误）。符号 = 操作数符号的异或。
0 / 0 → NaN / 错误⚠️ 部分合规返回 Err(FpError::Indeterminate)。在 FBig 层 panic。
∞ ± finite、∞ × finite 等 → ±∞❌ 偏离无穷是终态：将它们送入算术运算会返回 Err(FpError::InfiniteInput)。对无穷的运算需要在 Context 层显式处理或使用特殊情况方法。
exp(+∞) = +∞✅Context::exp 接受无穷输入。
exp(-∞) = +0✅同上。
exp_m1(+∞) = +∞✅
exp_m1(-∞) = -1✅
ln(±0) = -∞✅作为值产生。
sqrt(-0) = -0✅
sin(-0) = -0✅
向负舍入下的消去产生 -0✅add.rs 中的 cancel_zero 在 R::IS_ROUND_TOWARD_NEGATIVE 时产生 -0。
精确减法仅在定向舍入下消去为 -0✅IEEE 754 §6.3：(-3) + 3 在 roundTiesToEven/Up 下为 +0，在 Down 下为 -0。

第 5.3 节——舍入

IEEE 754 要求合规性说明
舍入模式：roundTiesToEven、roundTiesToAway、roundTowardPositive、roundTowardNegative、roundTowardZero✅全部五种模式实现为 HalfEven、HalfAway、Up、Down、Zero。
正确舍入到 1 ulp 以内✅所有运算保证 ∣error∣<1 ulp。算术、根号以及实超越函数（exp、exp_m1、ln、ln_1p、三角与双曲函数族、hypot、powi、powf）通过 Ziv 循环保证正确舍入；dashu-cmplx 的复数超越函数（exp、log、powf、powi、sin/cos/tan/sin_cos、asin/acos/atan、双曲函数 sinh/cosh/tanh/sinh_cosh 与 asinh/acosh/atanh、sqrt）经由其自身的 Ziv 循环正确舍入，同时认证实部与虚部（asin/acos 采用因式分解的 1−z2=(1−z)(1+z)，在奇点 z=±1 处亦保持精度；双曲函数族通过精确的旋转恒等式 sinh z = -i\sin(iz) 等复用圆函数，继承其认证）。Rounded 类型区分精确与非精确结果。
就近舍入保持零的符号✅rounded_to_repr 在舍入将非零值折叠为零时保持输入符号。

第 5.6 节——符号位运算

IEEE 754 要求合规性说明
abs(x) 始终非负✅FBig::abs() 将 -0 转换为 +0。
neg(x) 翻转 ±0 和 ±∞ 的符号✅通过 negate_special_exponent 正确翻转指数哨兵值。
signum(±0) = +0✅对 +0 和 -0 均返回 +0（signum 折叠零的符号）。
sign() 区分 +0 与 -0✅Repr::sign() 对 -0 返回 Negative。

转换

IEEE 754 要求合规性说明
f32/f64 往返保持 -0✅FBig::try_from(-0.0f64) 产生 -0。
f32/f64 往返保持无穷✅
转换到 f32/f64 时上溢产生 ±∞✅into_f32_internal / into_f64_internal 检查指数范围。
转换到 f32/f64 时下溢产生 ±0✅同上。
整数到浮点转换对可表示的整数是精确的✅
浮点到整数上溢饱和（按 Rust 惯例）不适用Rust 的 TryFrom 在上溢时返回错误；ToPrimitive 返回 None。

异常条件

IEEE 754 要求合规性说明
无效运算 → NaN❌panic（FBig）或返回 Err(FpError)（Context）。
除以零 → ±∞（无陷阱）✅
上溢 → ±∞（无陷阱）✅已检测并传播。
下溢 → ±0（无陷阱）✅同上。
不精确标志⚠️ 部分合规Rounded<T> 类型携带 Exact/Inexact(T, Rounding) 以指示是否发生了舍入，但没有粘性标志机制。

小结（dashu-float）

类别状态
有符号零✅ 完全合规
有符号无穷✅ 完全合规
上溢/下溢✅ 完全合规
定向舍入✅ 完全合规
NaN 处理❌ panic（设计如此）
算术中的无穷操作数❌ 错误（设计如此——无穷是终态）
次正规数不适用（无界精度）
异常标志⚠️ Rounded 类型指示精确/非精确，无粘性标志

dashu-cmplx 与 C99 Annex G

CBig 是一对 Repr 部分（实部和虚部），共享一个精度和舍入模式。它以 C99 Annex G（IEC 60559 兼容复数运算）为目标来实现通用功能，为每个部分复用 dashu-float 的有符号零 / 有符号无穷 / 支割线机制。与 FBig 一样，没有 NaN：C99 中会产生复数 NaN 的情形在 Context 层映射为 FpError（在便捷层 panic）。

无穷是终端值，与 dashu-float 一致。复数无穷是单一的黎曼点 +∞ + i·0；它由有限输入“爆炸”产生（z/0、exp(+∞)、上溢），但绝不被接受为操作数——任何接收无穷操作数的算术或超越运算都以 FpError::InfiniteInput 拒绝（在便捷层 panic）。这与 C99 Annex G 刻意不同：Annex G 承认逐部分无穷并为其定义结果（∞·∞ = ∞、∞/∞ = NaN 等）；dashu 则拒绝整类情形。已实现的特殊值矩阵见 复数运算中的无穷。

数据模型（§G.2）

C99 Annex G 要求合规性说明
复数为有序的实部/虚部对✅CBig<R, B> 在一个共享的 Context 上存储 re 和 im（Repr）。
每部分有符号零（±0）✅继承自 dashu-float；虚部零的符号选择支割线的侧。
每部分有符号无穷（±∞）✅每个部分可以独立为 ±∞；这样的值是终端输出，而非操作数。
单个复数无穷（黎曼点）✅proj 将任何部分为无穷的值折叠为 +∞ + i·0；上溢产生 +∞ + i·0。
复数 NaN❌ 偏离无 NaN。产生 NaN 的情形映射为 FpError（Context）/ panic（便捷层）。

算术（§G.5）

C99 Annex G 要求合规性说明
conj(z) 翻转虚部符号（包括 -0、±∞）✅精确翻转虚部符号（终端值的符号翻转，同 dashu-float 的 Neg）。
proj(z)：任何无穷 → +∞ + i·0✅投影后的虚部零保持原始虚部的符号。
∞·∞、finite·∞、∞·finite → ∞（C）❌ 偏离无穷是终端值：任何无穷操作数都以 FpError::InfiniteInput 拒绝（便捷层 panic）。
0·∞ → NaN（C）❌ 偏离FpError::InfiniteInput（在到达 0·∞ 之前就拒绝无穷操作数）。
finite/0、z/0（有限 z ≠ 0）→ ∞✅有限被除数除以零产生黎曼点 +∞ + i·0。
∞/finite、∞/∞（C）❌ 偏离以 FpError::InfiniteInput 拒绝（∞ 是终端值）。
finite/∞ → 0（C）❌ 偏离以 FpError::InfiniteInput 拒绝（无穷除数也是终端值）。
0/finite → 0✅
0/0 → NaN（C）⚠️ 部分合规Err(FpError::Indeterminate)（无 NaN）。
1/0 → ∞✅
1/∞ → 0（C）❌ 偏离以 FpError::InfiniteInput 拒绝。

超越函数与支割线（§G.6）

C99 Annex G 要求合规性说明
支割线遵循 Kahan 有符号零模型✅例如 log(−r±i⋅0)=lnr±iπ：虚部零的符号选择割线的侧。
sqrt(+∞) = +∞、sqrt(-∞) = +0 + i·∞（C）❌ 偏离以 FpError::InfiniteInput 拒绝（与同样拒绝的 dashu-float 的 sqrt 一致）。
exp(+∞) = +∞、exp(-∞) = +0✅dashu-float 的 exp 处理无穷实输入，故 exp(+∞ + i·0) = +∞ + i·0、exp(-∞ + i·0) = +0。
exp(0 + i·∞) → NaN（C）⚠️ 部分合规Err(FpError::Indeterminate)。
log(0) = -∞✅
log(+∞) = +∞（C）❌ 偏离以 FpError::InfiniteInput 拒绝（与同样拒绝的 dashu-float 的 ln 一致）。
arg(0+i⋅∞)=+π/2、arg(0−i⋅∞)=−π/2✅arg = atan2(im, re)，复用 dashu-float 的 Annex G atan2 表。
abs/hypot 上溢安全模运算✅在 dashu-float 的 hypot 上的薄组合层。

异常条件

C99 Annex G 要求合规性说明
无效/不定形式 → NaN❌ 偏离在 Context 层返回 Err(FpError::{Indeterminate, InfiniteInput})；在便捷层 panic。设计上无 NaN。
定义域错误（如负数的偶数根、超出范围的逆三角函数）❌ 偏离返回 Err(FpError::OutOfDomain) / panic，而非 NaN 结果。
每个分量独立按共享模式舍入✅每个轴经由同时认证两部分的 Ziv 循环正确舍入，与 dashu-float 的实超越函数一致（asin/acos 采用因式分解的 1−z2=(1−z)(1+z)，在奇点 z=±1 处亦保持精度）。

小结（dashu-cmplx）

类别状态
每部分有符号零与无穷✅ 完全合规
黎曼点单无穷 / proj✅ 完全合规
支割线（Kahan 有符号零模型）✅ 完全合规
算术与超越函数特殊值⚠️ 偏离 —— 无穷操作数被拒绝（FpError::InfiniteInput / panic）而非按 C99 求值；C99 中产生 NaN 的值以 FpError / panic 报告
复数 NaN❌ 设计上不存在
